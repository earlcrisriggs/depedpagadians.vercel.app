# SDO Pagadian Training Needs Analysis Web Application

This is a standalone, offline-first HTML web application.

## Included
- Evidence dashboard using data from the supplied SDO Pagadian QDEDP and Needs Analysis PPTX
- Automated ranked Training/L&D Needs Analysis
- QDEDP pillars and ELEVATE mapping
- DepEd 5-Point Reform Agenda mapping
- Role-based intervention suggestions
- Add local performance indicators and needs
- Memo alignment field for the exact governing memorandum
- Proposal Builder
- CSV/JSON export
- Browser print / Save as PDF
- Local browser storage for custom entries

## Important source limitation
Only two source files were supplied in this conversation: the QDEDP document and the Needs Analysis PPTX. No separate governing memorandum file was available. The app therefore does **not** claim memo compliance; it provides a memo-entry/alignment panel so the exact memo directives can be encoded without inventing requirements.

## Run
Open `index.html` in Chrome, Edge, or another modern browser.

No server or installation is required.
